# ColorChips

Nhóm service/rule dùng chung theo nghiệp vụ. Xem [tổ chức feature](../../README.md).

PDF sản xuất mẫu Tân Phú in mã VA cùng `StandardFormula` (Mã mẫu chuẩn) đã lưu khi có dữ liệu; nếu trống/null thì chỉ in VA. Bộ dựng PDF dùng chung không xóa mã mẫu chuẩn. Quy tắc này không đổi ngày in, bố cục hoặc mẫu in khác.
